The Best Halloween Game Ever
About the Project

The Best Halloween Game Ever is a 2D platformer game made with Python and Pygame. The player controls BOB and navigates through a world filled with platforms, obstacles, and interactive objects.

The game features platforming mechanics, environmental effects, sound effects, a very cool transistion and a house which you get trapped in.

Requirements

You will need Python and the following libraries:

Pygame
Pillow

The game also requires its image and audio assets to be available in the expected locations (Leave them in the folders they come in).

Installation
1. Install Python

Download and install Python from python.org.

2. Install the required libraries

Open a terminal in your project folder and run:

pip install pygame pillow

3. Check your project files

4. Run the game

Run the Python script from your terminal:

python "The-best-Halloween-game-ever.py"

Controls
Key	Action
A	Move left
D	Move right
W	Jump
S	Crouch
F   Interact
E   Open inventory

Or alternatively, download the .zip file, extract all the files and then run the application file.

Gameplay

Explore the level by jumping between platforms and navigating obstacles.

As you progress, the environment changes to include rain and lightning. To escape the bad weather, you enter a house, but the balcony collapses down behind you. You are trapped in this house, and you must find a way to escape.

Technologies Used
Python — Main programming language.
Pygame — Game window, input handling, collision detection, rendering, and audio playback.
Pillow (PIL) — Loading and resizing background images.
